Privacy policy

Last updated: 16 October 2026

Mail Coach is a private tool used only by its owner with the owner's own Google account. It is not available to anyone else.

Google user data

  • What it accesses: the Gmail API scope gmail.send, used only to send emails from the owner's account that the owner wrote or approved.
  • How it is stored: the OAuth token is stored on the owner's private server and is not shared with anyone.
  • Sharing: no Google user data is sold, shared with third parties, or used for advertising.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions.

Mail Coach's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
